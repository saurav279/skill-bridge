# Skill Bridge

Premium Global Talent Visa consultancy website — Next.js 15, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — Home
- `/about` — About
- `/case-studies` — Case study grid
- `/case-studies/[slug]` — Case study detail
- `/login` · `/register` — Dummy auth UI (no backend)

## Theme

Light / Dark / System via navbar toggle. Persisted in `localStorage` (`skill-bridge-theme`).
